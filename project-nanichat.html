Nanichat

Nanichat est une application web de messagerie développée en PHP. Elle offre un système avancé de salons de discussion : les utilisateurs peuvent créer des salons publics ou privés, inviter des membres spécifiques, et gérer les droits de chaque espace (propriétaire du salon, administrateur). Le système gère les autorisations dynamiquement pour l'affichage et l'envoi de messages en base de données.

Technologies utilisées

PHP (Architecture MVC) MySQL / PDO HTML/CSS Gestion de Sessions
