Automatisation

Bot Vinted

Ce projet consiste en un script d'automatisation développé en Python. Il permet de surveiller en temps réel les nouvelles annonces sur la plateforme Vinted selon des critères précis (marque, prix, état) et de publier une notification instantanée sur Discord pour saisir les meilleures affaires.

Technologies utilisées

Python API Rest Scraping JSON
Voir sur GitHub

Points techniques

  • Trois commandes Discord : !vinted renvoie une annonce correspondant à la recherche, !auto lance une surveillance qui vérifie les nouveautés chaque minute, !stop l'arrête.
  • Recherche souple : le bot accepte des mots-clés ou directement l'adresse d'une recherche Vinted, dont il reprend les filtres.
  • Appels à l'API : les requêtes passent par une session requests qui récupère d'abord les cookies du site, puis lit les réponses JSON.
  • Commande non bloquante : pour !vinted, l'appel réseau est exécuté en dehors de la boucle asynchrone de discord.py, pour que le bot reste réactif pendant la recherche.
  • Jeton protégé : le jeton Discord est lu dans une variable d'environnement, jamais écrit dans le code.
