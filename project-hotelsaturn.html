HotelSaturn

HotelSaturn est une plateforme web de gestion hôtelière complète. Elle permet aux clients de consulter les chambres disponibles avec un système de filtrage dynamique par prix et d'effectuer des réservations. Une section d'administration sécurisée est également intégrée pour le personnel afin d'ajouter, modifier ou supprimer des chambres. L'ensemble de l'infrastructure web et base de données est déployable via Docker.

Technologies utilisées

PHP / PDO Docker & Compose MariaDB HTML5 / CSS3
Voir sur GitHub

Points techniques

  • Contrôle de disponibilité : avant chaque réservation, une requête SQL vérifie qu'aucune réservation existante ne chevauche les dates demandées pour la chambre.
  • Facture automatique : une fois la réservation enregistrée, le client est redirigé vers sa facture, calculée à partir du nombre de nuits et du prix de la chambre. Un client ne peut consulter que ses propres factures, l'administrateur les voit toutes.
  • Deux rôles : client et administrateur, conservés en session. L'administrateur accède à un tableau de bord pour gérer les chambres et les comptes.
  • Sécurité : requêtes préparées PDO pour toutes les données saisies par l'utilisateur, et mots de passe hachés avec password_hash.
  • Base de données : trois tables (utilisateurs, chambres, réservations) sous MariaDB, dans un environnement Docker Apache / PHP.
